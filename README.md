# Random Quest - Telegram RPG Bot

Простой RPG бот для Telegram с элементами случайной генерации.

## Особенности

- Выбор класса персонажа (Воин, Маг, Лучник)
- Система уровней и опыта
- Случайные встречи с противниками
- Система боя
- Получение золота и предметов
- Простая инвентарная система
